## Description

Extends the core `core/button` block with:

- Interactivity API support (namespaced click/state directives for consumer blocks).
- A unified **Has Icon** block style backed by block attributes, replacing the old per-icon styles.

## Has Icon Style

Select the **Has Icon** style in the block styles panel to unlock the icon picker in the inspector sidebar. Once active, four attributes drive the icon:

| Attribute      | Type     | Default        | Description                                                            |
| -------------- | -------- | -------------- | ---------------------------------------------------------------------- |
| `iconLibrary`  | `string` | `solid`        | Font Awesome Pro library (solid, regular, light, brands, etc.)         |
| `iconName`     | `string` | —              | Icon slug (e.g. `arrow-right-long`)                                    |
| `iconPosition` | `string` | `right`        | `left` or `right` — which side of the button label the icon appears on |
| `iconColor`    | `string` | `currentColor` | CSS color value for the icon                                           |

The icon is rendered on the frontend via `::before` / `::after` pseudo-elements on the button using CSS `mask-image` with a data URI (generated by `\PRC\Platform\Icons\get_icon_as_data_uri()`). The color is applied separately via `background-color`, so no separate per-color asset is needed, and dark-mode adjustments are trivial.

The editor preview fetches the FA Pro sprite once per library session (cached in memory) and builds the same data URI client-side so the icon appears immediately.

## Legacy Styles (deprecated)

The old `icon__*` and `brand__*` block styles (`icon__arrow-right-long`, `brand__google`, etc.) are kept registered in PHP so existing content continues to render, but they no longer appear in the editor style picker. When a block that uses one of those legacy styles is next edited, it is automatically migrated to `is-style-has-icon` with the appropriate attribute values pre-filled.
