Navigation panels with InnerBlocks content controlled by the Interactivity API.

## Description

Container block for `prc-block/navigation-panel` child blocks. Builds a radio navigation list from each panel's label, optional icon, and return label. Supports left and top layouts on desktop and mobile, optional parent/child hierarchy, and Interactivity API panel switching with top-layout back navigation.

## Instructions

1. Insert the Navigation Panels block.
2. Configure each Panel child's label, return label, and optional icon in the block sidebar.
3. Use the block toolbar to add, remove, or reorder panels.
4. In the Navigation Panels sidebar, set navigation level, default panel, layout, navigation style, and options column width.

Full block documentation: `docs/plugins/prc-block-library/blocks/navigation-panels.md`
